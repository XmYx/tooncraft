# Feature names

Rules: craft-contrib `standards/naming.md` (RFC-0029). Our labels describe what the feature does in
ordinary words; no reference product's feature names.

Check record, 2026-11-17: the checks below were made from general knowledge of the reference apps'
public manuals and of other drawing apps that use the same words descriptively. The trademark
register searches (USPTO, EUIPO / TMview, WIPO) required by rule 4 have **not** been run yet; they
are due in the pull request that proposes ToonCraft. Until then every label is provisional.
