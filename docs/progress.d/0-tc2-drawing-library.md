- 2026-11-23: Drawing library: the shot keeps named, reusable runs of drawings with their timing. The Drawing Library panel adds the selected frames (or the drawing at the cursor) with its own copies of the drawings, inserts an item on the current layer as new drawings or linked (linked uses share the item's drawings, so drawing on one changes them all), and renames, reorders and removes items; each is one undo step and a command (`save_to_library`, `insert_from_library`, …). Saved in the shot, capped and repaired on load.
